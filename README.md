# RRT* Path Planning Implementation

This project implements the RRT* (Rapidly-exploring Random Tree Star) algorithm for path planning in a 2D environment containing static rectangular and circular obstacles.

## Description

The algorithm searches for an optimal (shortest) path from a given start point to a goal point while avoiding collisions with obstacles defined in the environment. It builds a tree structure by randomly sampling points and connecting them, progressively finding better paths through rewiring steps.

## Dependencies

* Python 3.x
* NumPy (`pip install numpy`)
* Matplotlib (`pip install matplotlib`)

## How to Run

1.  Make sure you have the required dependencies installed.
2.  Place `env_zh.py` (or `env.py`) and `rrt_star.py` in the same directory.
3.  Run the main RRT* script from your terminal:
    ```bash
    python rrt_star.py
    ```
4.  A Matplotlib window will pop up showing the environment, the explored tree (green lines), and the final path (red line).

## Parameters

You can adjust the following key parameters within the `rrt_star.py` file under the `if __name__ == '__main__':` block:

* `STEP_LEN`: The maximum length of each edge added to the tree.
* `SEARCH_RADIUS`: The radius used for finding near neighbors and rewiring (crucial for RRT* performance).
* `ITER_MAX`: The maximum number of iterations the algorithm will run.
